# C# and .NET Framework Laboratory

## 📘 About

This repository contains the **C# and .NET Framework Laboratory Experiments** performed as part of the undergraduate engineering curriculum.

The repository contains practical programs and laboratory exercises implemented using **C# programming language and the .NET Framework**. The experiments provide hands-on experience with programming concepts, object-oriented programming, .NET features, Windows-based application development, and related concepts.

The programs are organized for **college laboratory practice, practical record preparation, learning, and academic reference**.

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/jayasumithra/C-and-.Net-Framework.git
```

### 2. Open the repository

Open the downloaded repository folder.

### 3. Open the C# project

Open the corresponding:

```text
.sln
```

or project file in **Visual Studio**.

### 4. Build the project

Use:

```text
Build → Build Solution
```

### 5. Run the program

Press:

```text
F5
```

or select:

```text
Debug → Start Debugging
```

For console programs, the output will be displayed in the console window.

For Windows Forms programs, the graphical application will open as a desktop window.

## 🎯 Objectives of the Laboratory

The main objectives of this laboratory are to:

1. Understand the fundamentals of C# programming.
2. Develop programs using object-oriented programming concepts.
3. Understand classes, objects, methods, and constructors.
4. Implement inheritance and polymorphism.
5. Work with delegates, events, generics, and exception handling.
6. Develop event-driven applications using Windows Forms.
7. Understand the basic architecture and features of the .NET Framework.
8. Gain practical experience using Visual Studio.
9. Develop problem-solving skills through programming exercises.
10. Apply C# and .NET concepts to practical applications.
